## 📌 Sobre o projeto

O **ColheitaSmart** é uma plataforma web voltada a **pequenos agricultores**, criada para apoiar a gestão dos alimentos **depois da colheita**.

A proposta é reunir, em um ambiente simples, informações sobre os alimentos colhidos, orientações de acompanhamento, organização de vendas e visão financeira da produção. Assim, o agricultor pode acompanhar melhor suas colheitas e tomar decisões com mais informação.

## 🎯 Problema e solução

Após a colheita, alimentos podem sofrer perdas por dificuldades de conservação, falta de acompanhamento e desafios na comercialização. Pequenos produtores nem sempre contam com ferramentas acessíveis para organizar essas informações.

O ColheitaSmart propõe centralizar o acompanhamento da pós-colheita em uma interface intuitiva, facilitando o registro de alimentos, a visualização de cuidados necessários e a organização comercial.

## ✨ Funcionalidades

| Área | Descrição |
| --- | --- |
| **Minha Colheita** | Cadastro, consulta e acompanhamento das colheitas. |
| **Detalhes da Colheita** | Visualização das informações registradas para cada colheita. |
| **O que fazer hoje?** | Organização de orientações e prioridades relacionadas aos alimentos. |
| **Vender Colheita** | Área de anúncios e acompanhamento de vendas. |
| **Carteira** | Visualização de informações financeiras relacionadas às colheitas. |
| **Páginas institucionais** | Home, Sobre, Integrantes, FAQ e Contato. |

O projeto considera inicialmente seis alimentos: **tomate, banana, alface, morango, manga e batata**.

> **Observação:** recursos de inteligência artificial e integrações externas fazem parte da evolução planejada da solução. A disponibilidade de cada recurso depende da versão implantada.

## 🛠️ Tecnologias utilizadas no front-end

- **React** — construção das interfaces.
- **TypeScript** — desenvolvimento com tipagem estática.
- **Vite** — ambiente de desenvolvimento e build.
- **Tailwind CSS** — estilização e responsividade.
- **React Router DOM** — navegação entre páginas.
- **Lucide React** e **React Icons** — ícones da interface.

## 🚀 Como executar localmente

### Pré-requisitos

- Node.js e npm instalados.
- Git instalado (para clonar o repositório).

```bash
# Clone o repositório
git clone https://github.com/AndreL050690/colheitasmart-front.git

# Acesse a pasta
cd colheitasmart-front

# Instale as dependências
npm install

# Inicie o ambiente de desenvolvimento
npm run dev
```

Abra no navegador o endereço indicado pelo Vite no terminal (normalmente `http://localhost:5173`).

### Gerar a versão de produção

```bash
npm run build
```
