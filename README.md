## 📌 Sobre o projeto

O **ColheitaSmart** é uma plataforma web voltada a **pequenos agricultores**, criada para apoiar a gestão dos alimentos **depois da colheita**.

A proposta é reunir, em um ambiente simples e acessível, informações sobre os alimentos colhidos, orientações de acompanhamento, organização de vendas e visão financeira da produção.

Assim, o agricultor pode acompanhar melhor suas colheitas, identificar prioridades e tomar decisões com mais informação.

### 🌐 Plataforma online

O front-end do projeto está publicado na Vercel e pode ser acessado diretamente pelo navegador, sem necessidade de instalação.

**🔗 https://colheita-smart.vercel.app/**

## 🎯 Problema e solução

Após a colheita, alimentos podem sofrer perdas por dificuldades de conservação, falta de acompanhamento e desafios na comercialização.

Pequenos produtores nem sempre contam com ferramentas acessíveis para organizar essas informações, o que pode dificultar o aproveitamento da produção e comprometer sua rentabilidade.

O **ColheitaSmart** propõe centralizar o acompanhamento da pós-colheita em uma interface intuitiva, facilitando o registro de alimentos, a visualização de cuidados necessários e a organização comercial.

**Nosso objetivo é transformar informações em decisões que ajudem a reduzir desperdícios e valorizar o trabalho do pequeno agricultor.**

## 🚀 Como executar localmente

### Pré-requisitos

- Node.js e npm instalados.
- Git instalado para clonar o repositório.

### Instalação

```bash
# Clone o repositório
git clone https://github.com/ColheitaSmart/ColheitaSmart.git

# Acesse a pasta
cd ColheitaSmart

# Instale as dependências
npm install

# Inicie o ambiente de desenvolvimento
npm run dev
```

Abra no navegador o endereço indicado pelo Vite no terminal, normalmente `http://localhost:5173`.

### Gerar a versão de produção

```bash
npm run build
```

O comando realiza a compilação do projeto e gera os arquivos necessários para publicação.

### Acessar sem instalar

Se preferir, utilize diretamente a versão publicada:
